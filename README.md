## Evidence and data labels

Every analytical statement must use one of these evidence labels:

- **Verified:** Supported by an identified official or supplied source.
- **Supplied data:** Derived from the fictional/simulated assignment dataset.
- **Proposed:** A recommended specification not confirmed as existing.
- **Assumption:** Recorded in the Assumption & Verification Register.
- **Illustrative:** Included only to demonstrate format or structure.

Simulated results are never actual VELOOP user, earnings, withdrawal, revenue, retention, conversion, performance, or company statistics.
