VELOOP Rewards — Data Analytics Internship Project

Data Analyst Internship, Task 01 · Product analytics, data readiness & data management blueprint

Please note: this is a documentation and specification project. The deliverables are reports, spreadsheets, and engineering handoff documents — not a live analytics application or dashboard.

About this project

This project builds the analytics and data-readiness blueprint for the VELOOP Rewards platform during a Data Analyst internship. It maps the product's features, user actions, and reward mechanics from verified public sources only, and defines the events, fields, models, and KPIs the product will need for reliable analytics.

The work follows an evidence-first policy: every product claim is traced to a registered source, every feature is labelled Confirmed (Public Documentation), Proposed, or To Be Verified, and no simulated data is ever presented as actual VELOOP business statistics.

Control registers & evidence

  • Source & Verification Register — every cited source (SRC-001…SRC-011) with classification, limitations, and evidence label, including one explicitly EXCLUDED third-party repository.
  • Assumption & Verification Register — open questions (ASM-001…ASM-008) with owner, risk, and verification action.
  • Progress Tracker — the 25-day working schedule with per-day status.
  • Source availability log — 2026-11-10 and 2026-11-11 re-check — HTTP verification of all public sources used.
  • Stage 1 implementation plan.

Verification

Structure and deliverable checks are automated. On Windows PowerShell 5.1:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\tests\verify_stage1.ps1"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\tests\verify_stage2.ps1"

Both scripts currently pass (7/7 checks each), covering directory structure, the 21-deliverable register, the source and assumption registers, the progress tracker, and the structure of Deliverables 02 and 03.

Integrity policy

  • Public website content is treated as Public Website Source — documented product information, not verified internal engineering documentation.
  • No fabricated business metrics; no simulated data presented as actual users, earnings, withdrawals, revenue, retention, or conversion figures.
  • Marketing-page numbers are illustrative only and are excluded from all analysis.
  • Open questions are tracked as assumptions with named owners — nothing is silently assumed.
